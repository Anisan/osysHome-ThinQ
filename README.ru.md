# ThinQ - Интеграция LG ThinQ

![ThinQ Icon](static/ThinQ.png)

Интеграция с протоколом LG ThinQ v2 для управления и мониторинга устройств умного дома LG.

## Описание

Модуль `ThinQ` предоставляет интеграцию с протоколом LG ThinQ v2 для платформы osysHome. Он обеспечивает управление и мониторинг устройств умного дома LG, включая кондиционеры, стиральные машины, холодильники и другие.

## Основные возможности

- ✅ **Протокол ThinQ v2**: Нативная поддержка API LG ThinQ v2
- ✅ **Управление устройствами**: Управление умными устройствами LG
- ✅ **Мониторинг состояния**: Мониторинг состояния устройств в реальном времени
- ✅ **Интеграция MQTT**: Обновления в реальном времени на основе MQTT
- ✅ **Связывание свойств**: Связывание состояний устройств со свойствами объектов
- ✅ **Связывание методов**: Связывание команд устройств с методами объектов
- ✅ **Интеграция поиска**: Поиск устройств и состояний

## Панель администратора

Модуль предоставляет административный интерфейс для:
- Просмотра устройств ThinQ
- Настройки параметров устройств
- Управления состояниями устройств
- Связывания состояний со свойствами

## Конфигурация

- **API ключ**: Ключ API LG ThinQ (Personal Access Token)
- **Страна**: Код страны (по умолчанию: RU)
- **Client ID**: Уникальный идентификатор клиента

## Получение API ключа

1. Посетите https://connect-pat.lgthinq.com
2. Войдите в аккаунт ThinQ
3. Нажмите "ADD NEW TOKEN"
4. Введите имя токена
5. Выберите функции
6. Нажмите "CREATE TOKEN"
7. Скопируйте созданный токен

## Использование

### Добавление устройства

1. Перейдите в модуль ThinQ
2. Настройте API ключ в настройках
3. Устройства обнаруживаются автоматически
4. Свяжите состояния устройств со свойствами объектов

## Технические детали

- **Протокол**: API LG ThinQ v2
- **Библиотека**: thinqconnect
- **MQTT**: Обновления состояния в реальном времени через MQTT
- **Поддержка async**: Операции на основе asyncio
